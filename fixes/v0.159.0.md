## v0.159.0 Deprecations

### GitInfo

- `.GitInfo.Ancestor` → Use `.GitInfo.Parent` instead. A new `.GitInfo.Ancestors` method returns all ancestor commits.

### Minify configuration

- `minify.tdewolff.css.keepcss2` → Use `minify.tdewolff.css.version` instead.
- `minify.tdewolff.css.decimals` → Deprecated.
- `minify.tdewolff.svg.decimals` → Deprecated.
- `minify.tdewolff.html.keepconditionalcomments` → Deprecated.
- Config root `minify` (bool) → Deprecated.
- Config root `minifyOutput` (bool) → Deprecated.
